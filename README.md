# 鹿溪衛浴 · 內部知識問答（luxi-kb-chat）

以**單頁 HTML** 實作的內部知識庫問答機器人。知識庫內建在頁面裡，使用者輸入自己的 **Groq API Key** 後即可提問；金鑰只存在瀏覽器 localStorage，**不會**被傳到 Groq 以外的任何地方，也不會寫進程式碼。

> ⚠️ 「鹿溪衛浴」「A2O 精密零組件」皆為課程用的**虛構公司**，知識庫內容全部是虛構資料。

## 功能
- 💬 一頁式聊天介面：氣泡對話、打字動畫、深淺色模式自動切換
- 🔐 金鑰閘門：沒有 Groq API Key 無法使用；Key 存 localStorage，可一鍵更換/清除
- 📚 內建知識庫（鹿溪衛浴，虛構）：
  - 新人須知 2026 版（**2024 版已停用**，回答會自動以 2026 版為準並提醒）
  - 報價流程、退換貨辦法
  - 產品母稿 LX-350（規格／認證／保固，含【不可對外】內部資訊標記）
- 🏷️ 回答附「依據：文件名」標籤；碰到【不可對外】內容會加「⚠️ 內部資訊」警示
- 🚫 知識庫沒有的資訊會明說「知識庫裡沒有」，不編造

## 使用
1. 打開網頁（GitHub Pages 網址，或本地直接開 `index.html`）
2. 貼上 Groq API Key（[console.groq.com/keys](https://console.groq.com/keys) 免費申請，`gsk_` 開頭）
3. 開始提問，例如：
   - 「一般詢問要多久回覆？客訴呢？」
   - 「業務報價最多可以打幾折？」
   - 「LX-350 有沒有 WRAS 認證？」（考題：目前沒有，只能說可以評估送測）
   - 「閥芯壽命可以對外說多少？」（考題：只能說 50 萬次，100 萬次是內部測試中）

## 技術
- 純前端單頁（HTML + CSS + 原生 JS），無框架、無依賴
- LLM：Groq API（`llama-3.3-70b-versatile`，可切換 `llama-3.1-8b-instant` / `gpt-oss-20b`）
- 知識庫直接嵌入系統提示詞（全文件約 4.5KB，不需向量檢索）
- 金鑰驗證：呼叫 `/models` 確認有效

## 隱私
- 對話與金鑰只存在你的瀏覽器分頁／localStorage
- 送出的內容會經過 Groq 伺服器（模型推論所需）；請勿輸入真實個資
- 本 repo 不含任何金鑰或私密資料
